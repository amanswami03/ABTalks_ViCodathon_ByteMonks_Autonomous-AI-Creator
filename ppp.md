# Backend Prompts

1. Build an autonomous AI persona that can run on its own after initialization.
2. Create two backend endpoints: one to initialize the agent and one to fetch the feed.
3. Make the agent discover topics from live sources and choose which ones are worth publishing.
4. Give the agent a clear persona with a consistent voice and writing style.
5. Let the agent remember previously published posts so it does not repeat itself.
6. Add a scheduler so posts are generated over time instead of all at once.
7. Include rationale, relevance, and source details in every published post.
8. Connect the backend to a local PostgreSQL database and store agent history there.
